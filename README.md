# Tarea: Pizzas V2, iniciando con estructura de carpetas y archivos

## Endpoints

Listar todas las pizzas:
- `GET /api/v1/pizzas

Obtener una pizza por ID:
- `GET /api/v1/pizzas/:id

Agregar una pizza:
- `POST /api/v1/pizzas

Actualizar una pizza:
- `PUT /api/v1/pizzas/:id

Eliminar una pizza:
- `DELETE /api/v1/pizzas/:id
